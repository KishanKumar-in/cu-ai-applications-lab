# AI Applications Lab (CONT_26ECP-102 / 26ECP-102)
### Chandigarh University — Academic Session 2026–27

Comprehensive repository containing all official lecture presentations, lab manuals, worksheets, real-world datasets, and compiled master study packages for **AI Applications Lab (`CONT_26ECP-102`)** at Chandigarh University.

---

## 📚 Course Structure & Lab Syllabus

### **Unit 1: Data Pre-processing and AIML Algorithms**
- **Experiment 1.1:** Introduction to Data Pre-processing, Pandas, NumPy & Matplotlib for Data Analysis.
- **Experiment 1.2:** Exploratory Data Analysis (EDA) on Real-World Datasets (`data.csv`) using Descriptive Statistics, Correlation Heatmaps, and Outlier Boxplots.
- **Experiment 1.3:** Supervised Machine Learning Classifier Models (`heart.csv.csv`) — Data Splitting, Feature Scaling, Training, and Evaluation Metrics (Accuracy, Precision, Recall, F1, ROC-AUC).
- **Experiment 1.4:** Building & Comparing Multiple Classification Models (Logistic Regression, SVC, Decision Trees, Random Forest, KNN, Naive Bayes) using Stratified K-Fold Cross-Validation.

### **Unit 2: AI and Machine Learning Fundamentals with Azure AI Tools**
- **Experiment 2.1:** Foundations of Artificial Intelligence, Machine Learning, Deep Learning, Generative AI, LLMs vs. SLMs, and Autonomous AI Agent Architectures.
- **Experiment 2.2:** Azure Machine Learning Ecosystem, Foundation Models, Tokenization, High-Dimensional Vector Embeddings, Transformer Attention Mechanisms, and Prompt Engineering.
- **Experiment 2.3:** Generative AI & Natural Language Processing (NLP) — Text Preprocessing (Tokenization, Stopwords, Lemmatization, POS Tagging, NER) and Azure AI Language Studio.
- **Experiment 2.4:** Practical Implementation Case Studies and Lab Worksheets on Azure AI Tools.

### **Unit 3: Azure AI Services for NLP, Speech Processing, and Computer Vision**
- **Experiment 3.1:** Speech-Enabled AI Solutions with Microsoft Tools — Speech-to-Text (STT), Text-to-Speech (TTS), Audio Signal Processing, MFCC Feature Extraction, and Acoustic Modeling.
- **Experiment 3.2:** Vision AI Architectures & Computer Vision Workflows Using Microsoft Foundry — Digital Image Representation, Kernels, Spatial Convolutions, and Convolutional Neural Networks (CNNs).
- **Experiment 3.3:** Multimodal Information Extraction & Optical Character Recognition (OCR) — Document Layout Analysis, Form Recognizer / Azure AI Document Intelligence, and Structured Data Extraction.
